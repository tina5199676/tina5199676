# 👋 Hi，我是 Tina

## 關於我

具備 iOS/Android 與 IoT 產品介面設計經驗，熟悉 Figma、Human Interface Guidelines 及 Material Design 設計規範。結合前端開發能力，能從使用者體驗與工程實作角度思考，設計兼具易用性與實作可行性的介面，並善用 Claude Code、GitHub Copilot 協助開發。

### 實務經驗

- IoT App UI/UX 設計：使用 Figma 製作 iOS/Android 高擬真介面與 Prototype
- 設計規範：依照 Human Interface Guidelines、Material Design ，建立跨平台介面設計規範
- 跨平台響應式設計：負責 iOS/Android、不同手機尺寸的介面適配
- 設備配網流程設計：規劃 iOS/Android 藍牙配網、Wi-Fi 設定與使用者綁定介面
- Design System：定義 Typography、Spacing、Radius、Border Width 及 Safe Area 佈局規範
- Design Handoff/QA：與工程師協作確認 UI 規格、版面配置、元件及互動細節，確保實作符合原始設計規格與操作邏輯
- Vue.js 前端開發：使用 Vue 3 ＋ Vite ＋ Vuetify ＋ Pinia 開發 QC/Production 管理後台，實作環境區分、設備列表等功能
